Todo lo que necesitas para tu servidor

  

    
Arranca y detén
Inicia o apaga el servidor con un clic desde la misma ventana.

    
CPU y RAM en vivo
Consulta en tiempo real cuántos recursos consume tu servidor.

    
Consola en tiempo real
Lee el registro mientras ocurre y lanza comandos con historial para repetirlos al instante.

    
Gestión de jugadores
Expulsa, banea, da permisos de operador o cambia el modo de juego de cada jugador.

    
Whitelist y banlist
Edita las listas desde un editor visual, sin tocar archivos JSON.

    
Editor de server.properties
Ajusta la configuración del servidor desde la propia aplicación.

    
Copias de seguridad
Guarda tus mundos manualmente o de forma automática.
